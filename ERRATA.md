# CNAUS Errata (Non-Core)

This file records confirmed errata affecting published CNAUS Core Standard releases.

Errata do not retroactively change published tags. Corrections are applied through patch releases according to `VERSIONING.md` and the Governance process.

## How to file an erratum

1. Open an issue describing:
   - affected version/tag
   - affected document + section
   - why it is erroneous (normative impact)
   - proposed correction text (exact)
2. The CNAUS Root Authority reviews the report.
3. If confirmed, an entry is added below and a patch release is created.
