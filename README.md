# CNAUS Registry Core

CNAUS is a verifiable evidence layer for AI compliance.

It defines how AI governance evidence can be structured, versioned, validated, and verified — so audits become reproducible instead of narrative-based.

**Website and services:** [cnaus.org](https://cnaus.org)

---

## What this repository contains

This is the open technical core behind the CNAUS Evidence Sprint service.

It defines:

- **RFC0001** — Registry Framework: how evidence records are structured
- **RFC0002** — API Specification: how records are accessed
- **RFC0003** — Proof Layer: how integrity is verified
- **Feed Specification** — how evidence events are published and chained
- **Conformance Pack** — validation rules and PASS/FAIL logic
- **Schemas** — JSON schemas for machine-readable evidence records

The core is public so the evidence logic can be inspected and independently reviewed by anyone.

---

## What CNAUS is not

CNAUS does not provide legal certification and does not replace legal advice, ISO certification, or regulatory assessment.

CNAUS provides structured evidence, conformance-style validation, and reproducible documentation workflows that support compliance, vendor-risk, and audit-readiness processes.

---

## Getting started

If you want to use CNAUS for your organisation, start at [cnaus.org](https://cnaus.org).

If you want to implement or review the technical core, start with [RFC0001](RFCs/RFC0001_RegistryFramework.md).

For templates and implementation guidance, see the [adoption-pack](https://github.com/cnaus-system/adoption-pack).
